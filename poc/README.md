# Thule Sheets — PoC (этап 0)

Проверка движка и оболочки перед MVP: Univer Sheets 1.2.0 в React 19, тёмная тема, собственная оболочка в стиле macOS и демо-книга «Финансы 2026».

## Запуск

```bash
npm install
npm run dev     # http://127.0.0.1:5173
npm run build   # tsc --noEmit + vite build
```

## Что реализовано

- **Своя оболочка**: сайдбар, хлебные крошки, заголовок документа, меню, тулбар, строка формул, панель KPI, вкладки листов и статус-бар. Штатные шапка, тулбар, строка формул и футер Univer отключены.
- **Тёмная тема**: `darkMode: true` в Univer; акцент `#8B5CF6` через палитру `primary = purple`.
- **Демо-книга**: два листа, числовые форматы ₽ и %, объединённая строка «Итого», условная окраска разницы, статусы, кросс-листовая формула `SUMIF`.
- **KPI-панель**: живые значения из листа «Финансы» через Facade API (`getRawValues`), пересчёт по событиям команд.
- **Строка формул**: адрес ячейки, формула/сырое значение, Enter — запись, Escape — отмена; формулы пишутся через `setFormula`.
- **Автосохранение**: снапшот книги в `localStorage` с задержкой 700 мс и индикатором «Сохранено / Сохранение…».
- **Вкладки листов**: переключение и добавление через Facade API (`setActiveSheet`, `insertSheet`).
- **Тулбар**: undo/redo, шрифт и размер, Ж/К/Ч, цвет текста и заливки, выравнивание, объединение, форматы валюты и процентов.

## Проверено

- `tsc --noEmit` и production-сборка проходят.
- Правка ячейки `E2` пересчитывает зависимые формулы (`H2`, итоги) и KPI.
- Ж/К/Ч применяется к выделению, undo откатывает.
- Переключение и добавление листов работают, активная вкладка подсвечивается.
- Перезагрузка страницы восстанавливает книгу из снапшота.

## Находки и обходные пути

1. **Тёмная тема холста инвертирует цвета.** Univer в `darkMode` прогоняет цвета через матрицу инверсии (`CanvasColorService`). Поэтому стили снапшота задаются в светлой палитре и пре-инвертируются хелпером `invertStyleColors` в `src/univer/demoWorkbook.ts`. Передавать `darkBlueTheme` вместе с `darkMode` нельзя: получается двойная инверсия и светлый холст.
2. **Формулы из снапшота с неполными ссылками разрешаются не на том листе.** Воспроизведено на 1.2.0: после загрузки многослойного снапшота формула `=E2-G2` на листе «Финансы» считала значения из колонки `E` листа «Бюджет». Обход: хранить формулы полностью квалифицированными (`=Финансы!E2-Финансы!G2`). Это нужно проверить на сохранении: Univer сохраняет формулы, введённые пользователем, без имени листа. До этапа 2 нужно либо канонизировать формулы на бэкенде, либо переигрывать их через `setFormula` после загрузки.
3. **Формульный worker не пересчитывает.** При заданном `workerURL` (`@univerjs/preset-sheets-core/worker?worker`) правки не запускали пересчёт, значения оставались старыми. С отключённым worker (main-thread formula engine) пересчёт работает. Для PoC worker отключён; вернуться к нему при замерах 100k+ ячеек.
4. **Футер Univer конфликтует с тёмной темой.** Штатный sheet bar рисуется в светлых тонах, поэтому он отключён и заменён собственной панелью вкладок.
5. **Корневой div Univer выходит за пределы контейнера** и перекрывает нижнюю панель. Лечится `overflow: hidden` на `.sheet-canvas`/`.univer-host`.
6. **`getValues()` возвращает отображаемые значения** (с учётом числового формата). Для вычислений нужны `getRawValues()` / `getRawValue()`.
7. **Размер бандла** ~7 МБ (Univer и локали). Позже — code splitting и вырезание неиспользуемых локалей.
